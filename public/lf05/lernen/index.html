System- und Anwendungssoftware

Systemsoftware verwaltet Hardware und stellt grundlegende Dienste bereit. Anwendungssoftware unterstützt konkrete Aufgaben der Benutzerinnen und Benutzer.

Standard- und Individualsoftware

Standardsoftware wird für viele Kunden entwickelt. Individualsoftware wird für konkrete Anforderungen eines Unternehmens erstellt oder angepasst.

Rolle des Betriebssystems

Das Betriebssystem vermittelt zwischen Hardware, Programmen und Menschen. Es verwaltet Arbeitsspeicher, Prozesse, Dateien und Geräte.

Eingebettete Systeme

Eingebettete Systeme erledigen definierte Aufgaben innerhalb eines Geräts, zum Beispiel in einer Waschmaschine, einem Router oder einem Fahrzeugsteuergerät.

# Software-Beispiel
betriebssystem = "Windows"
anwendung = "Firefox"
print(betriebssystem, anwendung)
Merksatz: Systemsoftware ermöglicht den Betrieb, Anwendungssoftware löst konkrete Aufgaben.

Algorithmus und Programm

Ein Algorithmus ist eine eindeutige, endliche Abfolge von Schritten. Ein Programm ist die Umsetzung eines Algorithmus in einer Programmiersprache.

PAP und Struktogramm

Ein Programmablaufplan stellt Abläufe mit Symbolen dar. Ein Struktogramm zeigt Kontrollstrukturen in verschachtelten Blöcken.

Use-Case-Diagramm

Use Cases beschreiben, welche Funktionen ein System für externe Akteure bereitstellt.

Pseudocode

Pseudocode beschreibt Programmlogik unabhängig von einer konkreten Programmiersprache und hilft vor dem Codieren.

# Pseudocode: Login
name ← EINGABE
WENN name = "admin" ODER name = "trainer"
    AUSGABE "Login erfolgreich"
SONST
    AUSGABE "Login fehlgeschlagen"
Merksatz: Erst den Ablauf planen, dann den Code schreiben.

Variablen

Variablen speichern Werte unter einem Namen. Der Wert und sogar der Datentyp können sich während der Programmausführung ändern.

Wichtige Datentypen

  • int: ganze Zahl
  • float: Kommazahl
  • str: Text
  • bool: Wahrheitswert

Type Casting

Mit int(), float(), str() und bool() werden Werte umgewandelt.

Operatoren

+, -, *, /, //, % und ** führen Berechnungen durch. Vergleichsoperatoren liefern True oder False.

alter = 30
preis = 19.99
name = "Python"
aktiv = True

print(type(alter))
print(17 // 5, 17 % 5)
Merksatz: Der Datentyp bestimmt, welche Operationen sinnvoll möglich sind.

Strings und Escape-Zeichen

Strings speichern Text. \n erzeugt eine neue Zeile, \t einen Tabulator und \\ einen Backslash.

Indizes und Slicing

Ein einzelnes Zeichen wird über einen Index gelesen. Mit text[start:ende] wird ein Teilstring erzeugt.

Unveränderbarkeit

String-Methoden erzeugen einen neuen String. Der ursprüngliche String verändert sich nur, wenn das Ergebnis wieder gespeichert wird.

Nützliche Methoden

strip(), lower(), upper(), replace(), count(), isalnum().

text = "  Hallo Python Hallo  "
text = text.strip().lower()
print(text.replace("hallo", "hi"))
print("Python 3".isalnum())
Merksatz: String-Methoden liefern meist einen neuen Wert zurück.

Bedingungen

if prüft eine Bedingung. elif ergänzt weitere Fälle. else behandelt alle übrigen Fälle.

Boolesche Operatoren

and verlangt zwei wahre Bedingungen, or mindestens eine und not kehrt einen Wahrheitswert um.

Einrückung

Python erkennt zusammengehörige Anweisungen an der Einrückung. Falsche Einrückung verändert die Logik oder verursacht Fehler.

Typische Anwendung

Login-Prüfung, Altersprüfung, Ampelsteuerung, Versandkosten oder Menüauswahl.

farbe = input("Ampelfarbe: ").lower()

if farbe == "rot":
    print("Stehen bleiben")
elif farbe == "gelb":
    print("Bereit machen")
elif farbe == "grün":
    print("Losfahren")
else:
    print("Ungültige Farbe")
Merksatz: Bedingungen steuern, welcher Programmteil ausgeführt wird.

for-Schleife

Eine for-Schleife durchläuft Elemente einer Folge oder einen mit range() erzeugten Zahlenbereich.

while-Schleife

Eine while-Schleife läuft, solange ihre Bedingung wahr ist. Die Bedingung muss irgendwann falsch werden.

break und continue

break beendet eine Schleife. continue überspringt nur den aktuellen Durchlauf.

Debugging

Fehler werden durch Lesen der Meldung, Prüfen von Datentypen, Zwischenausgaben und schrittweises Testen eingegrenzt.

for zahl in range(1, 11):
    if zahl == 5:
        continue
    if zahl == 9:
        break
    print(zahl)
Merksatz: for zählt strukturiert, while wiederholt abhängig von einer Bedingung.
