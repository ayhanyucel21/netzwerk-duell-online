Zusammenfassung: Software wird nach Aufgabe und Zielgruppe unterschieden. Systemsoftware ermöglicht den Betrieb eines Computers; Anwendungssoftware löst konkrete Benutzeraufgaben. Programme werden aus Quellcode erzeugt und durch Compiler oder Interpreter verarbeitet.

Kurze Begriffsdefinitionen

Systemsoftware

Software, die Hardware verwaltet und grundlegende Dienste bereitstellt, zum Beispiel Betriebssystem und Treiber.

Anwendungssoftware

Software für konkrete Aufgaben, zum Beispiel Textverarbeitung, Browser oder Warenwirtschaft.

Standardsoftware

Für viele Kunden entwickelte Lösung mit allgemein nutzbaren Funktionen.

Individualsoftware

Für einen bestimmten Auftraggeber oder besonderen Geschäftsprozess entwickelte Lösung.

Betriebssystem

Schnittstelle zwischen Hardware, Anwendungen und Benutzern; verwaltet Prozesse, Speicher, Dateien und Geräte.

Treiber

Software, die dem Betriebssystem die Kommunikation mit einem Gerät ermöglicht.

Embedded System

Rechnersystem innerhalb eines Geräts mit einer klar begrenzten Aufgabe, etwa Router- oder Fahrzeugsteuerung.

Quellcode

Lesbarer Programmtext, der in einer Programmiersprache geschrieben wurde.

Compiler

Übersetzt ein Programm vor der Ausführung in eine ausführbare Form.

Interpreter

Verarbeitet und führt Quellcode während der Programmausführung schrittweise aus.

Debugging

Systematisches Finden, Eingrenzen und Beheben von Fehlern.

Jupyter Notebook

Arbeitsumgebung, in der Code, Ergebnisse und erklärender Text in Zellen kombiniert werden.

Beispiele und Vergleich

Software richtig einordnen

  • Windows: System- und Standardsoftware
  • Firefox: Anwendungs- und Standardsoftware
  • Router-Firmware: Systemsoftware eines Embedded Systems
  • Eigene Tourenplanung für eine Spedition: Individualsoftware

Kleines Python-Beispiel

betriebssystem = "Linux"
anwendung = "Firefox"
print(betriebssystem, anwendung)

Variablen speichern Werte; print() gibt Werte aus.

💡 Merksatz

Systemsoftware betreibt das System. Anwendungssoftware unterstützt die Arbeit des Benutzers.

⚠️ Typischer Fehler

„Vorinstalliert“ bedeutet nicht automatisch Systemsoftware. Entscheidend ist die Aufgabe der Software.

🎯 Prüfungs-Tipp

Bei „Welche Softwareart?“ zuerst Zweck, Zielgruppe und Anpassungsgrad markieren.

✅ Selbstkontrolle

Schlüsselwörter: Softwarearten · Betriebssystem · Compiler · Interpreter
Zusammenfassung: Ein Algorithmus beschreibt eine eindeutige und endliche Lösungsfolge. Vor dem Programmieren helfen Pseudocode, PAP, Struktogramm, Entscheidungstabelle und Use-Case-Diagramm dabei, Anforderungen und Abläufe verständlich darzustellen.

Kurze Begriffsdefinitionen

Algorithmus

Eindeutige, ausführbare und endliche Folge von Schritten zur Lösung eines Problems.

Programm

Technische Umsetzung eines Algorithmus in einer Programmiersprache.

Sequenz

Anweisungen werden nacheinander ausgeführt.

Auswahl

Eine Bedingung entscheidet, welcher Weg ausgeführt wird.

Wiederholung

Anweisungen werden mehrfach ausgeführt, gezählt oder bedingungsgesteuert.

Pseudocode

Sprachunabhängige, gut lesbare Beschreibung der Programmlogik.

PAP

Programmablaufplan: grafische Darstellung eines Ablaufs mit genormten Symbolen.

Struktogramm

Blockorientierte Darstellung von Sequenz, Auswahl und Wiederholung.

Use Case

Beschreibt eine Funktion, die ein System für einen externen Akteur bereitstellt.

Akteur

Externe Rolle, Person oder anderes System, das mit dem betrachteten System interagiert.

include

Zwingend eingebundener, wiederverwendeter Teilablauf eines Use Cases.

extend

Optionale Erweiterung eines Use Cases unter einer Bedingung.

Symbole und Beispiele

PAP-Symbole

  • Oval: Start oder Ende
  • Rechteck: Verarbeitung
  • Raute: Entscheidung
  • Parallelogramm: Ein- oder Ausgabe
  • Pfeil: Ablaufrichtung

Pseudocode: Login

Benutzername EINGEBEN
Passwort EINGEBEN
WENN Benutzername = "admin"
  UND Passwort = "geheim"
  AUSGABE "Zugriff erlaubt"
SONST
  AUSGABE "Zugriff verweigert"

Use Case: Online-Bücherei

Akteur: Leser

  • Buch suchen
  • Buch ausleihen
  • Ausleihe verlängern
  • Benutzer authentifizieren: möglicher include-Fall

Guter Algorithmus

  • eindeutig
  • endlich
  • ausführbar
  • deterministisch
  • zielgerichtet
💡 Merksatz

Erst Problem und Ablauf planen, dann programmieren und testen.

⚠️ Typischer Fehler

PAP zeigt den Ablauf; Use Case zeigt Systemfunktionen aus Sicht der Akteure.

🎯 Prüfungs-Tipp

Bei Reihenfolgefragen immer Eingabe → Verarbeitung → Ausgabe prüfen.

✅ Selbstkontrolle

Schlüsselwörter: Algorithmus · PAP · Struktogramm · Use Case · Pseudocode
Zusammenfassung: Variablen speichern Werte. Der Datentyp bestimmt, welche Operationen möglich sind. Python verwendet unter anderem int, float, str und bool. Eingaben über input() sind zunächst Strings und müssen für Berechnungen häufig konvertiert werden.

Kurze Begriffsdefinitionen

Variable

Name, der auf einen gespeicherten Wert verweist.

Datentyp

Legt Bedeutung, Darstellung und erlaubte Operationen eines Wertes fest.

int

Ganze Zahl, zum Beispiel 42 oder -7.

float

Kommazahl mit Dezimalpunkt, zum Beispiel 3.14.

str

Zeichenkette in Anführungszeichen, zum Beispiel "Python".

bool

Wahrheitswert: True oder False.

Type Casting

Gezielte Umwandlung eines Wertes, etwa mit int(), float(), str() oder bool().

Operator

Zeichen oder Wort für eine Operation, etwa +, %, ==, and.

EVA-Prinzip

Grundstruktur: Eingabe, Verarbeitung, Ausgabe.

TypeError

Operation ist für die beteiligten Datentypen nicht zulässig.

ValueError

Datentyp wäre grundsätzlich möglich, aber der konkrete Wert ist ungültig.

Debugging

Fehler reproduzieren, Meldung lesen, Ursache eingrenzen, korrigieren und erneut testen.

Operatoren und Beispiele

Rechenoperatoren

  • +, -, *, /
  • //: Ganzzahldivision
  • %: Divisionsrest
  • **: Potenz
print(17 // 5)  # 3
print(17 % 5)   # 2
print(2 ** 3)   # 8

Eingabe und Umwandlung

eingabe = input("Anzahl: ")
anzahl = int(eingabe)
print(anzahl * 5)

Ohne int() bleibt die Eingabe ein String.

Vergleiche

alter = 18
print(alter >= 18)  # True
print(alter == 18)  # True
print(alter != 18)  # False

Variablennamen

  • erlaubt: kunden_name, anzahl2
  • nicht erlaubt: 2anzahl, Leerzeichen
  • sprechende Namen statt x1
💡 Merksatz

input() liefert immer str. Vor dem Rechnen den benötigten Datentyp herstellen.

⚠️ Typischer Fehler

"5" + 2 erzeugt TypeError; int("abc") erzeugt ValueError.

🎯 Prüfungs-Tipp

Bei Codeanalyse zuerst Variablenwerte und Datentypen Zeile für Zeile notieren.

✅ Selbstkontrolle

Schlüsselwörter: Variable · Datentyp · Casting · Operator · EVA · Debugging
Zusammenfassung: Strings speichern Text. Einzelne Zeichen werden über Indizes gelesen; Teilstrings entstehen durch Slicing. Stringmethoden liefern neue Strings, weil Strings unveränderbar sind.

Kurze Begriffsdefinitionen

String

Folge von Zeichen in einfachen oder doppelten Anführungszeichen.

Index

Position eines Zeichens; das erste Zeichen hat Index 0.

Negativer Index

Zählt vom Ende; -1 bezeichnet das letzte Zeichen.

Slicing

Auslesen eines Teilbereichs mit [start:ende:schritt].

Escape-Zeichen

Sonderdarstellung mit Backslash, zum Beispiel \n, \t oder \".

Immutable

Unveränderbar: Methoden erzeugen einen neuen String statt den alten direkt zu ändern.

f-String

Formatierter String, der Variablen in geschweiften Klammern einsetzt.

Stringmethode

Funktion eines Stringobjekts, etwa lower(), strip() oder replace().

Methoden und Beispiele

Index und Slicing

text = "Python"
print(text[0])    # P
print(text[-1])   # n
print(text[1:4])  # yth
print(text[::-1]) # nohtyP

Nützliche Methoden

  • strip(): äußere Leerzeichen entfernen
  • lower(), upper(): Schreibweise ändern
  • replace(a,b): Text ersetzen
  • count(x): Vorkommen zählen
  • isdigit(), isalpha(), isalnum(): Zeichen prüfen

f-String und Kassenbeleg

artikel = "Tastatur"
preis = 39.90
print(f"{artikel}: {preis:.2f} EUR")

Dateiendung prüfen

datei = input("Datei: ").strip()
if datei.lower().endswith(".pdf"):
    print("PDF erkannt")
💡 Merksatz

Beim Slicing ist der Endindex nicht enthalten.

⚠️ Typischer Fehler

text.upper() ändert text nur, wenn das Ergebnis wieder gespeichert wird.

🎯 Prüfungs-Tipp

Indizes immer unter den String schreiben; dadurch werden negative Indizes und Slices sicherer.

✅ Selbstkontrolle

Schlüsselwörter: String · Index · Slicing · Escape · Methode · f-String
Zusammenfassung: Kontrollstrukturen steuern, welche Programmschritte ausgeführt oder wiederholt werden. if, elif und else treffen Entscheidungen. for eignet sich meist für bekannte Wiederholungen, while für bedingungsabhängige Wiederholungen. range() erzeugt Zahlenfolgen. break beendet eine Schleife, continue überspringt nur den aktuellen Durchlauf. Eine Endlosschleife entsteht, wenn die Abbruchbedingung niemals erreicht wird.

Kurze Begriffsdefinitionen

if

Führt einen eingerückten Codeblock aus, wenn die Bedingung True ist.

elif

Prüft eine weitere Bedingung, wenn vorherige Bedingungen nicht erfüllt waren.

else

Auffangfall ohne eigene Bedingung, wenn kein vorheriger Fall zutrifft.

and

Verknüpft Bedingungen. Das Gesamtergebnis ist nur dann True, wenn beide Bedingungen True sind.

or

Das Gesamtergebnis ist True, wenn mindestens eine Bedingung True ist.

not

Kehrt einen Wahrheitswert um: aus True wird False und umgekehrt.

for-Schleife

Durchläuft nacheinander Elemente einer Folge, eines Strings, einer Liste oder eines mit range() erzeugten Zahlenbereichs.

while-Schleife

Wiederholt einen Codeblock, solange die Bedingung True bleibt. Die Anzahl der Wiederholungen ist häufig vorher nicht bekannt.

range()

Erzeugt einen Zahlenbereich für Schleifen. Der Endwert ist immer ausgeschlossen.

break

Beendet die aktuell laufende Schleife sofort. Das Programm wird nach der Schleife fortgesetzt.

continue

Überspringt den restlichen Code des aktuellen Schleifendurchlaufs und startet den nächsten Durchlauf.

Endlosschleife

Schleife ohne erreichbares Ende, weil die Bedingung dauerhaft True bleibt oder der Kontrollwert nicht verändert wird.

Zähler

Variable, die während einer Schleife erhöht oder verringert wird, zum Beispiel mit += 1 oder -= 1.

Iteration

Ein einzelner Durchlauf einer Schleife.

Verschachtelte Schleife

Schleife innerhalb einer anderen Schleife. Die innere Schleife läuft für jeden äußeren Durchlauf.

Debugging

Systematisches Finden, Erklären und Beheben von Syntax-, Laufzeit- und Logikfehlern.

for-Schleife und range()

Bekannte Anzahl Wiederholungen

for zahl in range(5):
    print(zahl)

Ausgabe: 0, 1, 2, 3, 4. Der Endwert 5 ist nicht enthalten.

range(start, stop, step)

for zahl in range(2, 11, 2):
    print(zahl)

Ausgabe: 2, 4, 6, 8, 10. Start = 2, Ende = 11 ausgeschlossen, Schrittweite = 2.

Liste durchlaufen

server = ["DC01", "WEB01", "DB01"]
for name in server:
    print(name)

Die Schleife verwendet direkt jedes Element der Liste.

Verschachtelte Schleifen

for zeile in range(2):
    for spalte in range(3):
        print(zeile, spalte)

Die innere Schleife läuft 3-mal für jeden der 2 äußeren Durchläufe: insgesamt 6 Ausgaben.

while-Schleife und Abbruchbedingung

Kontrollierter Zähler

x = 0
while x < 5:
    print(x)
    x += 1

x += 1 sorgt dafür, dass die Abbruchbedingung erreicht wird.

Login mit maximal 3 Versuchen

versuche = 0
while versuche < 3:
    passwort = input("Passwort: ")
    if passwort == "geheim":
        print("Zugriff erlaubt")
        break
    versuche += 1

Die Schleife endet bei Erfolg durch break oder nach drei Fehlversuchen durch die while-Bedingung.

Menü bis zur Auswahl 0

auswahl = ""
while auswahl != "0":
    auswahl = input("1 = Start, 0 = Ende: ")
    if auswahl == "1":
        print("Programm startet")

Die Anzahl der Menüaufrufe ist nicht vorher bekannt. Deshalb passt while.

Endlosschleife vermeiden

# Fehlerhaft:
x = 1
while x < 5:
    print(x)

# Korrekt:
x = 1
while x < 5:
    print(x)
    x += 1

In der fehlerhaften Variante ändert sich x nicht. Die Bedingung bleibt immer True.

break und continue

break beendet die Schleife

for zahl in range(10):
    if zahl == 5:
        break
    print(zahl)

Ausgabe: 0, 1, 2, 3, 4. Bei 5 endet die Schleife vollständig.

continue überspringt einen Durchlauf

for zahl in range(5):
    if zahl == 2:
        continue
    print(zahl)

Ausgabe: 0, 1, 3, 4. Nur der Durchlauf mit 2 wird übersprungen.

Ungültige Werte überspringen

werte = [5, -2, 8, 0, 3]
for wert in werte:
    if wert <= 0:
        continue
    print(wert)

Nur positive Werte werden weiterverarbeitet.

Suche beim Treffer beenden

for server in serverliste:
    if server == "WEB01":
        print("Treffer gefunden")
        break

Nach dem Treffer sind weitere Prüfungen nicht mehr notwendig.

Kontrollstrukturen in Szenarien

FizzBuzz

for zahl in range(1, 101):
    if zahl % 15 == 0:
        print("FizzBuzz")
    elif zahl % 3 == 0:
        print("Fizz")
    elif zahl % 5 == 0:
        print("Buzz")
    else:
        print(zahl)

Der speziellste Fall, teilbar durch 15, muss zuerst geprüft werden.

Ampelsteuerung

farbe = input("Ampelfarbe: ").lower()
if farbe == "rot":
    print("stehen")
elif farbe == "gelb":
    print("warten")
elif farbe == "grün":
    print("fahren")
else:
    print("ungültige Eingabe")

Grenzwerte richtig prüfen

if preis >= 100:
    rabatt = 0.10
else:
    rabatt = 0

„Ab 100 Euro“ schließt den Wert 100 ein. Deshalb wird >= verwendet.

Boolesche Operatoren

if benutzer == "admin" and aktiv:
    print("Zugriff")

if rolle == "admin" or rolle == "trainer":
    print("Menü anzeigen")

Debugging-Grundlagen bei Schleifen

SyntaxError

Python-Syntax ist verletzt, zum Beispiel fehlender Doppelpunkt: while x < 5.

IndentationError

Ein Codeblock ist nicht oder falsch eingerückt.

TypeError

Eine Operation passt nicht zu den Datentypen, zum Beispiel "5" + 2.

ValueError

Der Typ wäre möglich, der konkrete Wert aber nicht, zum Beispiel int("abc").

NameError

Eine Variable wurde vor der Verwendung nicht definiert.

Logikfehler

Das Programm läuft, liefert aber ein fachlich falsches Ergebnis, etwa durch range(1, 5) statt range(1, 6).

Systematische Fehlersuche

  1. Fehler reproduzieren.
  2. Fehlermeldung und betroffene Zeile lesen.
  3. Variablenwerte und Datentypen prüfen.
  4. Schleifenbedingung und Zählerveränderung kontrollieren.
  5. Grenzwerte testen.
  6. Korrigieren und erneut ausführen.
💡 Merksatz

Bekannte Anzahl oder bekannte Folge: meist for. Wiederholen bis zu einer Bedingung: meist while.

⚠️ Typische Fehler

Endwert bei range() eingeschlossen denken, Zähler in while nicht verändern, break mit continue verwechseln oder Code falsch einrücken.

🎯 LZK-/IHK-Tipp

Erstelle bei Codeanalyse eine Tabelle mit Durchlauf, Zähler, Bedingung und Ausgabe. So werden Grenzwerte und Schleifenfehler sichtbar.
